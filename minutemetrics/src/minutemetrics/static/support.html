MinuteMetrics Support

Help with setup, pairing, syncing, and privacy.

MinuteMetrics syncs Apple Health Exercise Minutes from the iOS app to your own Home Assistant add-on for private competitions.

Marketing Dashboard

Setup Checklist

  • Install the MinuteMetrics Home Assistant add-on.
  • Set a private admin token in the add-on Configuration tab.
  • Set `network.server_url` to the HTTPS URL reachable by iPhones.
  • Create a competition and participant from the Admin page.
  • Scan the participant QR code in the MinuteMetrics iOS app.

Sync Troubleshooting

  • Confirm the iPhone can open the configured `network.server_url`.
  • Confirm Cloudflare or any reverse proxy forwards `/api/v1/sync/exercise-days`.
  • Check that the participant was added to the intended competition.
  • Rotate and rescan the pairing token if a phone was paired with an old server URL.

Privacy

MinuteMetrics only needs Apple Health Exercise Minutes for competition tracking. Data is stored on the Home Assistant instance configured by the user. Participant sync tokens should be treated as private credentials.

Contact

For app support, file an issue at github.com/kmcrandom/minutemetrics-ha/issues. Include the add-on version, iOS app version, whether sync is local or remote, and any relevant Home Assistant add-on logs.
